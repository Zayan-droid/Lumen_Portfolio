# 🚀 Quick Start Guide

## Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Start the Server
```bash
npm start
```

### Step 3: Open Your Browser
Navigate to: **http://localhost:3000/index.html**

---

## 📋 Important URLs

| Page | URL |
|------|-----|
| **Home Page** | http://localhost:3000/index.html |
| **Waitlist Form** | http://localhost:3000/waitlist.html |
| **Admin Dashboard** | http://localhost:3000/admin.html |

---

## 🎯 Testing the Waitlist

1. Go to **http://localhost:3000/waitlist.html**
2. Fill in the form:
   - School Name: "Test School"
   - Number of Students: 500
   - Contact Email: test@school.edu
   - City: "New York"
3. Click "Join Waitlist"
4. You'll be redirected to a confirmation page

---

## 👨‍💼 Admin Dashboard

Visit **http://localhost:3000/admin.html** to:
- ✅ View all waitlist entries
- 📊 See real-time statistics
- 🔄 Update school status (pending → contacted → onboarded)
- 🗑️ Delete entries
- ↻ Refresh data

---

## 🛑 Stopping the Server

Press `Ctrl + C` in the terminal where the server is running.

---

## 💾 Data Storage

All waitlist data is saved in `waitlist-data.json` in your project folder.
